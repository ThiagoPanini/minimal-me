# Protótipo: direções visuais do MVP, rodada 1

Fonte do canvas [Direções do Minimal Me](https://claude.ai/artifact/N9JuwPgrR1CZt4NXHnGGMB), do ticket [Protótipos das direções visuais do MVP](https://github.com/ThiagoPanini/minimal-me/issues/21). Branch descartável: guarda a rodada 1 como foi avaliada e nunca é mesclado.

- `canvas.json`: índice do canvas, com posição e tamanho de cada artboard.
- `*.dc.html`: um artboard por arquivo. Prefixos A (Painel), B (Horizonte) e C (Órbita); `Main.dc.html` é a home da A no desktop.

O Autor manteve só a B (Horizonte). Os arquivos `B-*.dc.html` são o backup dela; a rodada 2 parte deles.
