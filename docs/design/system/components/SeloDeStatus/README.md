Uma etiqueta pequena sobre a imagem que diz em palavras o status de uma frente.

- **Você fornece**: o status. "Em desenvolvimento" usa ponto cheio, que pulsa; "Em planejamento" usa ponto vazado e texto mais fraco. "Disponível" não leva selo.
- **Quando usar**: sempre que a exposição da imagem indicar um status. A palavra garante que o estado não dependa só da imagem.
- Posição: canto superior esquerdo da imagem, a `selo-recuo` das bordas.
- Fundo `selo-fundo` com desfoque de 8px atrás, borda `selo-borda`, texto em `selo`, cor `selo-texto`.
- O selo é informativo: não recebe foco nem clique.
- Não crie selos de outras cores nem use o selo para categorias ou contadores.
