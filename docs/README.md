# Referências visuais

Wallpapers usados como referência de clima para o design do Minimal Me.
São arte de terceiros: extrair princípios, não reproduzir. O mascote e as
ilustrações do produto devem ser originais.

| Arquivo | O que extrair | O que ignorar |
|---|---|---|
| `01-manga-panels.png` | Grade de painéis como representação dos espaços; hachura, retícula e linhas de velocidade como o único "cinza" permitido; universo de conteúdo nostálgico (games retrô, café, leitura); o gato como figura recorrente. | Os personagens e obras específicos retratados nos painéis. |
| `02-cat-horizon-clock.png` | Espaço negativo extremo; ilustração de linha única; tipografia fina e espaçada; a linha horizontal como elemento estrutural; o assistente "espiando" como presença (estados vazios, loading, entrada do chat). | — |
| `03-figure-ripples-cosmos.png` | Metáfora para a home: "eu" no centro, espaços orbitando; ondas concêntricas como conhecimento se consolidando; estilo ink para ilustrações; clima contemplativo. | — |

Direção comum: fundo preto puro, linhas em branco puro, sem cor; ilustração
vale mais que "chrome" de interface; tom calmo, contemplativo, nostálgico e
brincalhão.
